## TVD Rally 3.2.65

Актуальный публичный выпуск для Windows 10 / 11.

### Что нового

- Общий чат TVD для общения всех пилотов проекта.
- Настройки уведомлений каждого чата: все сообщения, только упоминания или без уведомлений.
- Звук уведомлений включается по желанию; настройки сохраняются в аккаунте.
- Упоминания через @ник и кнопка «Упомянуть» в общем и командном чатах.

### Как запустить

1. Скачайте файл **TVD-Rally-3.2.65.zip** в разделе **Assets** ниже.
2. Полностью распакуйте архив в отдельную папку. Не запускайте приложение прямо из архива.
3. Откройте папку **TVD Rally** и запустите **TVD Rally.exe**.
4. Войдите с аккаунтом сайта TVD Rally и нажмите **«Поехали»**.

Если удобнее установка с ярлыками, используйте [установщик с сайта](https://tvdrally.online/launcher): после установки лаунчер предложит обновление до актуального выпуска.

Для игры нужны DiRT Rally 2.0 в Steam и аккаунт TVD Rally. Инструкция и условия участия — на [странице лаунчера](https://tvdrally.online/launcher), [вопросы и ответы](https://github.com/L3xi4/tvd-launcher-dr-2.0/blob/main/FAQ.md).

Файл **SHA256SUMS.txt** содержит контрольную сумму архива. Автоматические архивы **Source code** относятся к странице проекта; для запуска скачивайте **TVD-Rally-3.2.65.zip**.
